## Map data and tools (not distributed with this repository)

- **Map data © SCS Software.** PlasmaTrack is not affiliated with or endorsed by SCS Software.
  Basemaps are generated by each operator from their own game install, for modding purposes
  only. No map data is included in this repository.
- **truckermudgeon/maps** (GPL-3.0) generates the basemap tiles. It runs as a separate tool,
  and only its output files are used. No code or styles from it are included here. Its use
  of SCS data is allowed only if nothing is sold, so PlasmaTrack must stay non-commercial.
- **tippecanoe** (BSD-2-Clause) is used by truckermudgeon/maps to write the PMTiles archives.
- **MapLibre** and **PMTiles** are credited on every rendered route image.
